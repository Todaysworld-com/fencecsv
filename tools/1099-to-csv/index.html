Questions

Which 1099 forms work?
Any 1099 variant issued as a text-layer PDF by a payer or payroll platform. The layout logic is generic in this free version; the Verified Batch service applies the per-form column spec (NEC/MISC box maps) with a two-pass human check.
How should I store the output?
Professionals keep only the last 4 digits of any TIN/SSN in working spreadsheets and delete source files after processing. The paid batch service follows that rule contractually; do the same with your own downloads.
