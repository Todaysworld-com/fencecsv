Questions

Can I convert statements from multiple months?
Convert each month's PDF and append the CSVs — the column layout is identical every time, deliberately, so files stack. Bulk conversion of a full year is a Verified Batch job below.
What banks are supported?
Any bank whose PDF statements contain a real text layer (you can test: if you can select and copy text in the PDF, it will work). Layouts vary; unusual statements are flagged in the output notes rather than mangled quietly.
