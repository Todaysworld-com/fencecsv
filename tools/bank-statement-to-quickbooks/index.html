Questions

Which QuickBooks versions import CSV?
QuickBooks Online imports CSV for bank data directly; QuickBooks Desktop imports via its own CSV utilities. The flat layout here is the common denominator for both.
Is my statement uploaded anywhere?
No. There is no server component to this tool — open your browser's network tab and convert a statement: the file is never transmitted. That is the whole design.
