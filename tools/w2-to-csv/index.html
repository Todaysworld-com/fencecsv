Convert a W-2 PDF into spreadsheet rows

Payroll and tax-prep work means moving W-2 figures into spreadsheets, and a W-2 is the one document you should never upload to a conversion website: it carries a full Social Security number. This tool runs entirely in your browser — there is no upload, because there is no server. It pulls the text layer of a digital W-2 PDF into structured rows you can review and download as CSV. A note on discipline, borrowed from professional extraction practice: in any spreadsheet you keep, record Social Security numbers as last-4 only. The full number should live in the source document, nowhere else.

Questions

Is any of this sent to a server?
No. The W-2 is read by your browser's own PDF engine. Nothing is transmitted, stored, or logged — close the tab and the data ceases to exist.
Does it handle the official IRS W-2 PDF?
It extracts the text layer of digital W-2s, including payroll-provider PDFs. Scanned W-2s are read by in-browser OCR when there is no text layer, under the same rule: in any spreadsheet you keep, record the Social Security number as last-4 only.
