Questions

Why CSV and not .xlsx?
CSV is the format Excel, Google Sheets and tax workpaper systems all import without conversion prompts. Open the CSV in Excel and Save As .xlsx if you need styling — thirty seconds, same data.
Does it handle scanned W-2s?
No — scans need OCR. It extracts the text layer of digital W-2s, including payroll-provider PDFs, and tells you plainly when a file has no text layer. The Verified Batch service handles scans under a last-4-only privacy rule.
